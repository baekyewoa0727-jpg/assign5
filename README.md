프로젝트
영화 관리 프로그램을 제작했습니다. 기능은 제목, 감독, 개봉날짜, 별점, 후기를 다양한 input타입으로 입력하여 영화 목록을 관리할 수 있도록 구현했습니다 

create: 
form에서 submit이 발생하면 create함수를 실행합니다. 입력된 값을 하나의 객체로 만들고 새 영화의 여부를 판단한 후 배열에 저장합니다. form reset을 사용해 입력 후의 폼을 초기화 합니다 

read: 
render함수를 이용하여 배열의 데이터를 html 요소로 변환합니다 
기존 목록들을 제거 하고 forEach를 사용해 배열의 영화를 순서대로 확인합니다. p와 버튼 요소를 생성하고 appendChild를 통해 생성된 요소를 list에 추가합니다 

update: 
각 영화의 수정 버튼을 생성한 후 수정 버튼을 누르면 객체를 editMovie에 저장합니다. 저장버튼을 누르면 editmovie가 null이 아니므로 새 객체를 추가하지 않고 기존 값을 수정합니다 

delete: 
삭제 버튼을 누르면 confirm으로 삭제 여부를 확인합니다. splice(index, 1)을 사용하여 해당 위치의 객체 하나를 배열에서 제거합니다. (ai 이용-splice(index, 1)에서 index는 삭제할 배열의 위치이고, 1은 해당 위치에서 객체 하나를 삭제한다는 의미.)


validation:
각 요소마다 HTML의 required를 사용해 필수 입력을 하도록 구현했습니다.

문제 및 해결:

영화 수정과 추가를 같은 저장 버튼으로 처리하는 과정에서
현재 수정 중인 영화와 새로운 영화를 구분해야 하는 문제가 있었습니다.
이를 해결하기 위해 ai 도움을 받아 
editMovie 변수를 사용했습니다.
editMovie가 null이면 새로운 영화로 판단하여 배열에 추가하고,
null이 아니면 기존 영화의 값을 수정하도록 구현했습니다.

또한 영화 삭제 후 변경된 내용이 화면에 바로 표시되도록
splice()로 배열의 데이터를 삭제한 후 render()를 호출했습니다.

AI 활용:
JavaScript 코드를 작성하면서 코드의 사용 방법과 동작 원리를 이해하기 위해 AI를 활용했습니다.
splice(index, 1)의 사용 방법과
form.reset()을 이용한 폼 초기화 방법을 확인했습니다.
AI가 제공한 코드를 그대로 사용하기보다 직접 코드를 실행하고 수정하면서
각 코드가 어떤 역할을 하는지 확인했습니다.

느낀 점:
Array와 DOM을 이용하여 데이터를 추가하고 화면에 출력하는 과정을 이해할 수 있었습니다.
forEach(), splice(), createElement(), appendChild() 등을
직접 사용하면서 배운 개념들을 이해할 수 있었습니다 .
